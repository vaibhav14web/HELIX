# Helix

A Context-Aware Personal Cognitive Operating System.

## Architecture

- `docs/` - Project documentation and specifications
- `backend/` - Python backend (to be organized per SAD layers)
- `ui/` - React + TypeScript + Tailwind CSS + Framer Motion frontend

## Getting Started

### UI (Frontend)

```bash
cd ui
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
# Add backend run instructions as implemented
```
