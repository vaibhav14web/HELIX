# 1. Purpose

This document defines the visual identity of Helix.

The UI exists to provide visibility.

The UI should not become the product itself.

The user should always be able to continue their work while Helix runs.

The UI is a companion, not a distraction.

---

# 2. UI Philosophy

Helix UI should feel:

Alive

Calm

Fast

Intelligent

Trustworthy

The UI should never feel:

Robotic

Crowded

Over animated

Gamified

Distracting

Heavy

---

# 3. Design Principles

DP1

Information before aesthetics.

DP2

Animation with purpose.

DP3

Low cognitive load.

DP4

Minimal clicks.

DP5

Low GPU usage.

DP6

Everything accessible within two clicks.

# 5. Color Philosophy

Use adaptive colors.

Dark Mode:

Primary:

Near Black

Secondary:

Dark Gray

Accent:

Adaptive AI Accent

Light Mode:

Primary:

White

Secondary:

Light Gray

Accent:

Adaptive AI Accent

Rules:

Maximum 1 accent color.

Avoid rainbow interfaces.

Avoid neon overload.
