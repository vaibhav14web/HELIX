# 6. User Stories

## US-01 Voice Interaction

As a user

I want to communicate naturally

So that I can work without relying entirely on the keyboard.

Acceptance:

* Hindi support
* English support
* Hinglish support
* <3 second response time

---

## US-02 Persistent Memory

As a user

I want Helix to remember my work

So that I never repeat context.

Acceptance:

* 7 day rolling memory

* Memory survives restart

* Project history maintained

---

## US-03 Project Awareness

As a user

I want Helix to understand my active project

So that it can help intelligently.

Acceptance:

* Detect active project

* Load previous work

* Detect project switches

---

## US-04 Browser Awareness

As a user

I want Helix to understand my research environment.

Acceptance:

* Read tabs

* Organize tabs

* Open tabs

* Close tabs

---

## US-05 Permission System

As a user

I want complete control.

Acceptance:

Every action:

Observe

↓

Suggest

↓

Explain

↓

Permission

↓

Execute

---

## US-06 Coding Companion

As a user

I want silent coding assistance.

Acceptance:

* Detect being stuck

* Detect code smells

* Detect repetitive errors

* Notification first

---

## US-07 Learning Companion

As a user

I want personalized learning assistance.

Acceptance:

* Track DSA patterns

* Detect weaknesses

* Recommend topics

* Explain bilingually

---

## US-08 Productivity Companion

As a user

I want workflow optimization.

Acceptance:

* Detect repetitive tasks

* Suggest automations

* Reduce manual work
